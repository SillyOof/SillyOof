### SillyOof here 👋

Hey, I'm SillyOof — I spend most of my time writing Rust and C, building terminal tools, and poking around Linux internals just to see how things tick. I'm drawn to anything low-level: if it touches syscalls, memory layouts, or shaving microseconds off a hot path, I'm probably already interested. Lately I've been getting deeper into WebAssembly too, exploring what happens when you take systems-level thinking to the browser and beyond.
